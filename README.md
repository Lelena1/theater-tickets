# theater-tickets

Агент для Claude Desktop, который каждый день ищет недорогие билеты (до 5000 ₽, чем дешевле, тем лучше) на выбранные спектакли в театрах Москвы: Театр Наций, Театр им. Вахтангова, МХТ им. Чехова, РАМТ, «Практика».

Агент только ищет и читает афиши. Он ничего не покупает и не бронирует, не входит в аккаунты и не обходит капчи.

## Как устроен

- [`prompt.md`](prompt.md) — инструкция агента: список спектаклей, бюджет, источники, формат отчёта.
- Агент запускается как задача по расписанию (Scheduled task) в Claude Desktop каждый день в 9:00, с рабочей папкой этого проекта.
- `data/state.json` — память между запусками (известные даты, минимальные цены, статус продаж), чтобы отмечать, что изменилось.
- `data/reports/report-ГГГГ-ММ-ДД.md` — ежедневные отчёты.

Папка `data/` не хранится в репозитории (см. `.gitignore`).

## Как изменить список спектаклей

Отредактируйте `prompt.md` и попросите Claude обновить задачу по расписанию `moscow-theater-tickets` новым текстом.
